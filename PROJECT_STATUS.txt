1. PROJECT GOAL
--------------------------------------------------------------------------------
d-cron is an embeddable Go library that provides safe, coordinated cron-style 
job scheduling across an arbitrary number of container replicas — using ONLY 
the existing PostgreSQL database your application operates.

Key Goal: Prevent N replicas from executing the same scheduled job N times 
simultaneously, with zero new infrastructure dependencies (no Redis, no etcd, 
no standalone daemon clusters, zero table migrations for Phase 1 core).
