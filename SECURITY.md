# Security Policy

## Supported Versions

`d-cron` maintains security support for the current minor release series.

| Version | Supported          |
| ------- | ------------------ |
| v0.x    | :white_check_mark: |

## Reporting a Vulnerability

The `d-cron` team takes the security of our library seriously. If you discover a security vulnerability, please report it responsibly.

### How to Report

**Do NOT report security vulnerabilities through public GitHub issues.**

Instead, please report security issues directly to the maintainers by emailing:

- **Email**: `security@mindfiredigital.com` (or open a Private Vulnerability Report on GitHub)

Please include as much of the following information as possible:

1. **Type of issue**: (e.g. credential leakage, race condition, advisory lock bypass, SQL injection hazard).
2. **Steps to reproduce**: Clear instructions or a minimal reproducible Go example.
3. **Affected versions**: The version or commit hash where the vulnerability was observed.
4. **Potential impact**: What an attacker could achieve by exploiting the vulnerability.

### Response & Handling Process

- **Acknowledgement**: We will acknowledge receipt of your vulnerability report within 48 hours.
- **Assessment**: We will assess the severity and impact of the reported vulnerability within 5 business days.
- **Fix & Disclosure**: Once a fix is developed and verified, we will issue a patch release and publish a security advisory. We request that you maintain confidentiality until the patch is publicly released.

Thank you for helping keep `d-cron` and its community safe!
